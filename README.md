# 📈 NIFTY BANK Web Scraping

## 📌 Project Overview

This project demonstrates how to scrape historical NIFTY BANK index data using Python. The scraped data is processed and exported into a CSV file for further analysis.

This project was developed as part of a Data Science interview assignment to showcase web scraping, data collection, and data handling skills.

---

## 🚀 Features

- Scrapes historical NIFTY BANK data
- Extracts market information from the source
- Saves the data into CSV format
- Clean and reusable Python code

---

## 🛠️ Technologies Used

- Python
- Requests
- JSON
- Pandas
- CSV

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/NIFTY-BANK-Web-Scraping.git
```

2. Install the required libraries

```bash
pip install pandas requests
```

3. Run the script

```bash
python download_nifty.py
```
